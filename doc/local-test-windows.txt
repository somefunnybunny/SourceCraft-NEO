SOURCECRAFT NEO - LOCAL ENGINEER TEST
====================================

This is an early compatibility test, not a finished release.

INSTALL
-------

1. Stop the TF2 dedicated server.

2. Copy everything beside this file into:

       C:\TF2Server\tf

   Merge folders when Windows asks. Do not delete your existing Metamod or
   SourceMod installation.

3. Start the dedicated server normally.

4. In the SERVER console, check the plugins:

       sm plugins list

   ResourceManager, Advanced Infinite Ammo, SourceCraft NEO Ammopacks,
   SourceCraft NEO Gravity Gun, SourceCraft, ShopItems, Burrow, Human Alliance,
   Terran SCV, Terran Battlecruiser, Protoss Probe, Zerg Drone, TF2teleporter,
   and amp_node should all appear without an error state.

5. Start normal TF2. In the TF2 developer console, connect with:

       connect 127.0.0.1:27015

6. In chat, enter:

       changerace

   Choose Terran SCV, Protoss Probe, or Zerg Drone. All three are unlocked in
   this local test profile; their original source requirements have not been
   changed.

7. In the SERVER console, add bots with:

       tf_bot_add 11

USEFUL TEST COMMANDS
--------------------

Open the SourceCraft menu from the TF2 developer console:

    sc_menu

Set the current race to its maximum test level from the SERVER console:

    sc_setlevel "your player name" 49

SCV has 49 levels. Probe has 33, so SourceCraft will cap the command at 33
when Probe is selected. You can also level normally through the accelerated
short-term progression included in this package.

Drone has 27 levels. To test Creep immediately, select Drone, set its level to
27, and buy at least one level of Creep from the upgrade menu.

WHAT TO TEST FIRST
------------------

Terran SCV:

- Teleporter recharge upgrade
- Repair Node building conversion
- Building health regeneration
- Sentry shell and rocket replenishment
- Ammopacks drop on death; at level 2+, use sm_ammopack or +ultimate5 to drop
  one on demand. Wrench alt-fire remains exclusively TF2's building pickup.
- Gravity Gun carries completed buildings without using TF2's native pickup.
  SCV-held buildings remain disabled. Level 2 permits other players' buildings,
  Level 3 permits manual wrench repairs while held, and Level 4 permits throws.

Protoss Probe:

- Warp Gate teleporter recharge
- Shield Batteries automatic repair
- Engineer metal replenishment
- Sentry shell and rocket replenishment

Zerg Drone:

- Creep buildings reject all wrench work, including construction boosts,
  repairs, resupply, upgrades, and wrench-based sapper removal
- Creep adds 15/30/45/60 maximum building health and regenerates
  4/8/12/16 health per second
- An enemy Sapper deals at most 60% of the building's maximum health, then
  fizzles and detaches automatically
- Creep restores dispenser/sentry supplies and grows the upgrade meter by
  3/6/9/12 points per second
- At 200 metal, the building performs its normal automatic upgrade
- Carried and redeploying buildings receive no Creep repair, ammunition, or
  upgrade progress; their prior level resumes after placement

The default HUD should remain visible during active rounds in local no-database
mode. Its right block shows your current race, race and overall levels, current
XP, XP required and remaining for the next level, crystals, +crystals, and
Vespene. Energy, armor/shields, and exceptional health remain in the left block.

For convenient ultimate keys, enter these in the TF2 developer console:

    bind c +ultimate5
    bind mouse3 +ultimate
    bind mouse4 +grav
    bind v +rotate

For Gravity Gun testing, buy at least one Gravity Gun level and aim at a fully
constructed building. Press mouse3 once to grab it; hold and release mouse3 on
the next press to throw it when the race level permits. Mouse4 toggles a grab
or performs a safe drop, and V rotates the held building. Automatic repair,
refill, and upgrade effects pause until the building has landed.

Battlecruiser's Gravity Accelerator uses the same controls. Its carried
buildings remain disabled at levels 1-2, remain operational while held at level
3, and remain operational when thrown at level 4. Ship Propulsion is expected
to remain disabled because Jetpack is not in this package yet.

Remote remains quarantined from this Gravity Gun test build. Tripmine, Grenade,
Firemines, and Jetpack are also not part of this package slice yet. Their
related SCV, Drone, Probe, Battlecruiser, and ShopItems "not available" startup
messages are expected and do not mean the package failed to load.

IF SOMETHING FAILS
------------------

Run this in the SERVER console:

    sm plugins list

Then look in:

    C:\TF2Server\tf\addons\sourcemod\logs

The useful files are named errors_YYYYMMDD.log. Preserve the complete error
message and the numbered plugin list; both identify the next compatibility
fix far more reliably than a screenshot of the game alone.
